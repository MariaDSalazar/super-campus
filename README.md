# Súper Campus

Juego de plataformas de **Bases de Datos I · Semana 6 · Dependencias funcionales** (UIDE), con casos de una universidad.

El estudiante recorre el campus de corrido, como en un juego de plataformas clásico: salta, junta créditos, aplasta bichos y, en cada reto, golpea con la cabeza los bloques que lo resuelven. El juego no se detiene: cada respuesta se califica al instante y los niveles pasan solos al siguiente.

- 6 niveles y 22 retos con la tabla Matricula (estudiantes, materias y docentes): semántica de los atributos, redundancia, anomalías, valores NULL, tuplas espurias, cómo se comprueba X → Y y tipos de dependencia funcional, con un jefe final.
- Al terminar, un **informe de entendimiento** por tema, calculado con el primer intento de cada reto, con la lista de lo que conviene repasar. Se puede copiar o imprimir.
- Para jugar: https://mariadsalazar.github.io/super-campus/ (o con el código de `QR-Super-Campus.png`). Funciona en el navegador del celular o del computador, sin cuentas ni instalación. El avance se guarda en el mismo navegador.
